# Programming in C  Formative1
This repository contains implementation for `Low Level Programming module Programming in C formative 1`. From question one up to question four, it contains source codes, screenshots and documentation as well.

##  Repository Structure
- `screenshots/`: subdirectory for questions's program screenshots 
- `question1.c`: C program demonstrating basic calculations
- `question2.c`: menu-driven application using loops, conditional statements, and break/continue control statements
- `question3.c`: program showcasing function reuse and a matrecursive function
- `question4.c`: C++ code for controlled light system
- `README.md`: This documentation guide.


## Question 1
1. After opening your terminal, compile tquestion2 source code via :
   ```bash
   gcc question2.c -o
   ```
2. Run the executable:
   ```bash
   ./a.out
   ```
